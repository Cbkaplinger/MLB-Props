# ADR Template

> Copy this file to `docs/adr/NNNN-short-title.md`. Accepted only with repo
> evidence below. Without durable evidence, write `docs/adr/PROPOSED-*.md`
> or skip the ADR. See `docs/agent/skills-catalog.md` (`/write-adr`).

# ADR-NNNN: Title

- **Status:** Proposed | Accepted | Superseded
- **Date:** YYYY-MM-DD
- **Context:** What problem, what constraints, what was true at the time.
- **Decision:** What was decided, in one paragraph.
- **Alternatives:** What else was considered and why it lost.
- **Consequences:** What follows from this (code, policy, ops).
- **Evidence:** Repo paths, artifact hashes, report keys, test names. Required for Accepted.
- **Revisit trigger:** What future fact would reopen this.
- **Related code:** Canonical modules/paths.
- **Related experiments:** Cards, manifests, reports.
